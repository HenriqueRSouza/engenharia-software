## 📌 Objetivo do Exercício

Compreender e aplicar na prática os conceitos de **Versionamento Semântico** (`MAJOR.MINOR.PATCH`):
- **MAJOR (`v2.0.0`)**: Mudanças estruturais incompatíveis na API/sistema (Breaking Changes).
- **MINOR (`v1.1.0`)**: Adição de novas funcionalidades mantendo total retrocompatibilidade.
- **PATCH (`v1.1.1`)**: Correções de bugs retrocompatíveis sem alterar o comportamento esperado.
